# Project Guidelines & Rules

## Strict No-Emoji Policy
- **Never use emojis in the UI, code, dialogs, alerts, progress bars, notifications, or user-facing text.**
- Emojis appear unprofessional, render inconsistently across platforms (macOS, Windows, Linux, Android, iOS), and clash with modern obsidian/minimalist design languages.
- Always use clean, minimalist inline SVG icons (e.g. Feather / Lucide icon aesthetic: `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`, `stroke-width="2"`, `stroke-linecap="round"`, `stroke-linejoin="round"`).
- In status dialogs and modal messages, use plain, professional terminology (e.g., "Notice:", "Success:", "Security Warning:") rather than prepending decorative emoji pictograms.
- In buttons and labels, pair text with crisp SVG icons rather than emojis.
